# Radiografias dos materiais

Cada material já tem um caminho reservado no catálogo. Coloque nesta pasta a
radiografia usando o nome de arquivo da tabela e peça para indexá-la; a imagem
será ativada nos cards e na janela de detalhes. Até lá, o site mostra uma
ilustração esquemática identificada como provisória.

Use arquivos JPG (`.jpg`). Se preferir PNG, atualize a extensão no campo `image`
do material correspondente em `js/app.js`. Ao indexar uma foto, o campo
`imageReady` do material também deve ser alterado de `false` para `true`.
